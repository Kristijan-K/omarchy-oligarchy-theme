# Omarchy Oligarchy Theme

Full-theme scaffold for Omarchy using the Oligarchy vault artwork palette:
charcoal stone, antique gold, parchment, burnt red, olive, and blue-gray.

## Install

```bash
omarchy theme install https://github.com/Kristijan-K/omarchy-oligarchy-theme
```

## Included

- `colors.toml`: Omarchy palette source
- `icons.theme`: Yaru file-manager icon theme
- `preview.png`: Theme selector preview
- `preview-unlock.png`: Unlock selector preview
- `unlock.png`: Boot unlock artwork
- `backgrounds/`: Theme wallpapers
- `btop.theme`: btop override
- `chromium.theme`: Chromium color override
- `hyprland.lua`: Hyprland border override
- `shell.lock.toml`: Lock-screen shell override

The terminal, editor, shell, and application configurations are generated by
Omarchy from `colors.toml` when the theme is applied.
